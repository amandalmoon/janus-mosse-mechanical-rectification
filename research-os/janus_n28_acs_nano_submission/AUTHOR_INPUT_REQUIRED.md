# N28 Author Input Required Before ACS Upload

The venue-formatted manuscript is complete except for author-controlled metadata that must not be inferred.

Required:
- exact full author names and order;
- affiliations and author-affiliation mapping;
- corresponding-author mailing address and email;
- funding sources plus grant/award numbers, or explicit no-funding confirmation;
- competing financial interest disclosure;
- all-author approval and exclusive-submission confirmation;
- preprint status;
- prior ACS Nano editor discussion status;
- Review-Only Material status;
- final human-created non-AI TOC graphic.

ACS Nano urges 6-8 reviewer suggestions; these are recommended but not treated here as a manuscript-format blocker.

The technical manuscript contains visible placeholders so it cannot be mistaken for a final upload copy.
