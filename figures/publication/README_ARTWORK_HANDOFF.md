# Artwork Handoff

Use the SVG files in `figures/` as the editable masters. They explicitly declare Arial.

Before ACS Nano upload on a workstation with Arial installed:

1. Open each SVG and verify that all figure text resolves to literal Arial.
2. Keep the physical width at <= 7.0 in (double-column).
3. Confirm minimum lettering >= 6 pt and line width >= 0.5 pt at final size. Current design targets 7 pt and >=0.6 pt.
4. Re-export EPS at final size and, if a raster derivative is needed, export RGB TIF at appropriate final-size resolution.
5. Inspect all six final files at 100% final published size for clipping, font substitution, symbol changes, and legend overlap.
6. Do not alter data, limits, uncertainty, normalization, panel selection, or captions during the font/export handoff.

No font files are included in this package.
